## Eagle Works Official Firmware ##

# Official Firmware Used in FTC Team 32272's Robot for the 2026-27 Season#

Currently Supported:
* Mechanum Drive
* GoBuilda Pinpoint odometry support
# Controls
| Input | Output |
| --- | --- |
| Left Stick Y | Drive Forward/Back |
| Left Stick X | Strafe Left/Right |
| Right Stick Y | Turn Left/Right |
| Right Stick X | Unbound |
| Start | Reset Heading |
